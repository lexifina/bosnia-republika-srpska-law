# Члан 126.
Брисање мјере из евиденције
(1) Ако полицијски службеник у року од годину дана од дана коначности рјешења којим му је изречена дисциплинска мјера за лакшу повреду дужности не учини нову повреду, изречена мјера се брише из евиденције.
(2) Ако полицијски службеник у року од три године од дана коначности рјешења којим му је изречена дисциплинска мјера за тежу повреду дужности не учини нову повреду, изречена мјера се брише из евиденције.
