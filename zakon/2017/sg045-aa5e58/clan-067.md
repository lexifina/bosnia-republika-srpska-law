# Члан 67.
Приходи туристичких организација
Приходи туристичких организација су:
1) приходи из буџета оснивача,
2) приходи од боравишне таксе, осим ако посебним законом није другачије прописано,
3) приходи од обављања послова из члана 66. овог закона,
4) кредитног задужења уз претходну сагласност оснивача,
5) донација и
6) других извора.
