# Члан 98.
Застарјелост извршења споредне казне и мјера безбједности
(1) Застарјелост извршења новчане казне као споредне казне настаје кад протекне пет година од дана правноснажности пресуде којом је та казна изречена.
(2) Застарјелост извршења мјера безбједности настаје кад протекне пет година од дана правноснажности одлуке којом су те мјере изречене.
