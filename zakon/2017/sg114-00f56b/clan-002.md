# Члан 2.
(1) Регистар запослених код корисника буџетских средстава Републике Српске (у даљем тексту: Регистар), представља скуп података о корисницима буџетских средстава, података о запосленима код корисника буџетских средстава, као и података о личним примањима тих лица.
(2) Регистар се успоставља ради праћења броја запослених код корисника буџетских средстава и њиховим личним примањима.
