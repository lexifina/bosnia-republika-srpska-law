# Члан 2.
У члану 75. у ставу 2. ријечи: "31. децембра 2016. године" замјењују се ријечима: "30. јуна 2017. године".
У истом члану после става 2. додаје се нови став 3. који гласи:
''(3) Власници оружја за личну безбједност који су до дана ступања на снагу овог закона предали своје оружје надлежном органу због истека рока важења оружаног листа, могу поднијети захтјев за замјену оружаног листа, до истека рока из става 2. овог члана, уз испуњење услова из члана 11. став 3. и став 4. тачка 1. овог закона''.
Досадашњи став 3. постаје став 4.
