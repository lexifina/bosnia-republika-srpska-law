# Члан 20.
(1) Потраживања и обавезе учесника који су укључени у Коначни извјештај из члана 18. овог закона престају даном спровођења мултилатералне компензације.
(2) Учесници су дужни да у сопственим пословним књигама умање потраживања и обавезе према другим учесницима за износе који су укључени у извјештај из члана 18. овог закона.
