# Члан 88.
Интерна контрола рада овлашћених сервиса
(1) Овлашћени произвођач дужан је да врши интерну контролу рада овлашћених сервиса које је овластио на основу члана 77. став 3. овог закона.
(2) Ако овлашћени произвођач у току контроле из става 1. овог члана, утврди да овлашћени сервис не поступа у складу са одредбама овог закона, дужан је да овлашћеном сервису одузме овлашћење из члана 77. став 3. овог закона, у року од осам дана након утврђене неправилности.
(3) Овлашћени произвођач је дужан да на захтјев ПУ, поступи на начин из става 2. овог члана, када ПУ у поступку контроле утврди да овлашћени сервис не поступа у складу са одредбама овог закона.
(4) О одузимању овлашћења из ст. 2. и 3. овог члана, овлашћени произвођач обавештава Комисију, ПУ и обвезника у року од три дана након одузимања овлашћења.
(5) Овлашћени произвођач је дужан да у року од осам дана од дана укидања овлашћења из ст. 2. и 3. овог члана, обвезнику обезбиједи други овлашћени сервис.
(6) Ако овлашћени произвођач не поступи на начин из става 5. овог члана, Комисија покреће поступак за укидање регистрације произвођача сагласно члану 50. овог закона, о чему писмено обавјештава овлашћеног произвођача.
