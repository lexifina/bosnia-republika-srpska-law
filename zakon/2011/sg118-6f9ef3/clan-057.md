# Члан 57.
(1) Власник стана подноси тужбу надлежном суду са захтјевом за исељење закупца из његовог стана и за предају стана, односно дијела стана у посјед, уколико закупцу обезбиједи одговарајући стан по основу закупа на неодређено вријеме, у складу са одредбама овог закона које регулишу закуп стана, али не већи од стана који је користио.
(2) Власник стана који је закупац на другом стану у државној својини може поднијети тужбу суду са захтијевом за замјену стана који користи по основу закупа са закупцем на стану у његовој својини.
