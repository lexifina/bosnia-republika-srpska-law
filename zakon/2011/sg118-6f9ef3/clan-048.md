# Члан 48.
(1) Без дозволе закупца нико се не може уселити у стан који закупац користи.
(2) Закупац може из оправданих разлога од сваког члана породичног домаћинства, осим малољетне дјеце, брачног друга, као и лица која је по закону дужан да издржава, тражити исељење из стана, остављајући му за исељење примјерен рок.
(3) Ако се лице из става 2. овог члана не исели у остављеном року, закупац може тужбом путем суда тражити његово исељење.
