# Члан 29.
Порез по одбитку
(1) Порез по одбитку обрачунава се и плаћа при исплати прихода страном правном лицу по стопи од 10% на укупно исплаћени приход.
(2) У смислу става 1. овог члана, укупни приход је приход који би се исплатио страном правном лицу да порез није одбијен од исплаћеног прихода.
