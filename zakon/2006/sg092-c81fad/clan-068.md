# Члан 68.
(1) Показатељ укупних трошкова фонда не може бити већи од 3,5% просјечне годишње нето вриједности имовине фонда. Комисија сваке године, по завршетку годишњег обрачунског периода, објављује сажето поређење показатеља укупних трошкова свих затворених инвестиционих фондова са јавном понудом.
(2) Све настале трошкове који у одређеној години пређу највиши допуштени показатељ укупних трошкова у висини од 3,5%, сноси друштво за управљање.
