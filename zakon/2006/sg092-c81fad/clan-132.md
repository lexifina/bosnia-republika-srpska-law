# Члан 132.
4. Трошкови отвореног инвестиционог фонда са приватном понудом
Накнаде које се наплаћују инвеститору, односно отвореном инвестиционом фонду са приватном понудом ограничене су на:
а) улазну накнаду која се одбија од износа уплате у тренутку продаје удјела,
б) излазну накнаду која се одбија од нето вриједности имовине фонда по удјелу у тренутку откупа,
в) накнаду за управљање.
