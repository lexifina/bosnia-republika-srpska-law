# Члан 209.
4. Трошкови отвореног инвестиционог фонда ризичног капитала са приватном понудом
Накнаде које се наплаћују инвеститору, односно отвореном инвестиционом фонду ризичног капитала са приватном понудом ограничене су на:
а) улазну накнаду која се прибраја нето вриједности имовине фонда по удјелу у тренутку продаје,
б) излазну накнаду која се одбија од нето вриједности имовине фонда по удјелу у тренутку откупа,
в) накнаду за управљање.
