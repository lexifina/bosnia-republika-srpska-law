|Укупна накнада за управљање + укупни износ свих осталих трошкова из члана 66. овог закона, осим трошкова | |
|из става 1. тачке ј) и л) тог члана | |
| |× 100 |
|Просјечна годишња нето вриједност имовине | |
| | |
(2) Износ трошкова из става 1. овог члана мора се објавити у ревидираном годишњем извјештају фонда.
