# Члан 49.
(1) За ученике који заостају у савладавању наставног програма, током школске године организује се допунска настава.
(2) Припремна настава организује се за ученике упућене на поправни испит, прије почетка испитног рока, у трајању од најмање пет радних дана по два часа дневно за сваки предмет.
