# Члан 76.
(1) Послодавци су дужни да своје опште акте ускладе с одредбама овог закона у року од шест мјесеци од дана ступања на снагу прописа из члана 74. овог закона.
(2) Акт о процјени ризика из члана 13. ст. 1. и 2. овог закона послодавци су дужни да донесу у року од годину од дана ступања на снагу акта из члана 13. став 4. овог закона.
