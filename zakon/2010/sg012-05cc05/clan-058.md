# Члан 58.
1) Привремено одузимање имовине траје до окончања кривичног поступка, односно поступка по захтјеву за трајно одузимање имовине у држави молиљи. Инострани орган свака 90 дана доставља обавјештење домаћем суду о току поступка.
2) Ако поступак из става 1. овог члана не буде окончан у року од двије године од доношења рјешења о привременом одузимању имовине, суд ће по службеној дужности укинути рјешење.
