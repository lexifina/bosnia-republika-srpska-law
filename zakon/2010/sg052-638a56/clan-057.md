# Члан 57.
(1) Пружалац услуга брише се из Регистра пружалаца услуга, ако:
а) престане да испуњава услове из члана 54. став 2. и члана 55. став 2. овог закона,
б) не пријави промјену података у року из члана 56. став 4. овог закона и
в) поднесе захтјев за брисање из Регистра пружалаца услуга.
(2) Брисање из Регистра пружалаца услуга врши се на основу рјешења које доноси министар.
