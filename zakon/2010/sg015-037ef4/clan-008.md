# Члан 8.
(1) Угоститељ регистрован као привредно друштво, има неограничену одговорност, а власник, односно сувласници, неограничену солидарну одговорност за штету проузроковану трећим лицима која је изазвана давањем нетачне изјаве о испуњавању услова из члана 7. став 3. овог закона.
(2) Угоститељ регистрован као предузетник има неограничену одговорност за штету проузроковану трећим лицима која је изазвана давањем нетачне изјаве о испуњавању услова из члана 7. став 3. овог закона.
(3) Угоститељи који имају закључен уговор о ортаклуку солидарно су одговорни за штету проузроковану трећим лицима која је изазвана давањем нетачне изјаве о испуњавању услова из члана 7. став 3. овог закона.
(4) Министар упутством прописује садржај изјаве из члана 7. став 3. овог закона.
