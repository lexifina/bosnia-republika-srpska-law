# Члан 28.
1) Поступци за расправљање имовинско-правних односа насталих узурпацијом земљишта који нису окончани по раније важећем пропису окончаће се по одредбама овог закона.
2) Поступци из чл. 25. и 26. овог закона окончани по раније важећем пропису, могу се на захтјев добровољца или његових правних сљедника поновити у складу са одредбама овог закона у року од три године од дана ступања на снагу овог закона.
