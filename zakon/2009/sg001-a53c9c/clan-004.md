# Члан 4.
Насљеђивање ванбрачних сродника и сродника из потпуног усвојења
(1) Ванбрачно сродство изједначава се у погледу насљеђивања са брачним, а сродство потпуног усвојења са сродством по крви.
(2) У случају потпуног усвојења престају међусобна насљедна права усвојеника и његових потомака са његовим сродницима по крви.
