# Члан 24.
1) Буџетски корисници који у својој надлежности имају ниже буџетске јединице, обавезни су да им прослиједе инструкције из чл. 22. и 23. овог закона.
2) Буџетски корисници из става 1. овог члана обавезни су да израде збирни буџетски захтјев за све буџетске јединице у својој надлежности, а према инструкцији Министарства.
