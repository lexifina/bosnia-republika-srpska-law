# Члан 81.
(1) Ради спровођења поступка за стицање звања, научно вијеће образује комисију која се састоји се од најмање три истраживача из научне области у којој кандидат стиче звање, од којих најмање један није у радном односу у организацији која образује комисију.
(2) Чланови комисије не могу бити у нижем звању од звања које кандидат стиче.
