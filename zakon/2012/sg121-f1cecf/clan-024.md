# Члан 24.
У члану 48. ст. 2. и 5. бришу се.
Ст. 3. и 4. мијењају се и гласе:
"(3) Сви купци природног гаса су квалификовани купци, осим купаца из категорије домаћинства, који су тарифни купци и природни гас купују према регулисаним цијенама.
(4) Тарифни купци природног гаса из става 3. овог члана стичу статус квалификованог купца почев од 1. јануара 2015. године."
