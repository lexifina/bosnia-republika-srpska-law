# Члан 23.
У члану 44. у ставу 2. ријеч: "Министарство" замјењују се ријечима: "Влада одлуком".
Послије става 2. додаје се нови став 3. који гласи:
"(3) Ветеринарска служба финансира се:
а) из средстава оснивача у складу са актом о оснивању,
б) из буџетских средстава за мјере које одреди Министарство,
в) из средстава прикупљених пружањем ветеринарских услуга и
г) из других средстава."
Досадашњи став 3. постаје став 4.
