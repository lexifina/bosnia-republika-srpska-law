# Члан 403.
Поступање по молби страног органа
Када Министарство правде Републике Српске прими молбу страног органа за правну помоћ, дужно је да молбу достави надлежном тужиоцу.
О дозвољености и начину извршења радње која је предмет молбе иностраног органа одлучује суд, односно тужилац по домаћим прописима.
