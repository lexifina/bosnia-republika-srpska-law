# Члан 31.
(1) Привредно друштво запошљава инвалиде без јавног оглашавања потребе за радницима.
(2) Уколико за одређено радно мјесто има више инвалида који испуњавају услове радног мјеста од броја извршилаца који се примају, предност утврђује орган који је упутио инвалиде, односно Завод, за инвалиде који су незапослени.
