# Члан 28.
(1) Цертификовани органски производи из увоза обавезно су упаковани и затворени на начин који спречава замјену њихове садржине.
(2) Цертификовани органски производи из увоза могу се стављати у промет ако је за те производе овлашћена контролна организација издала потврду из члана 19. став 2. овог закона.
(3) Министар доноси правилник којим се прописује поступак издавања потврде из члана 19. став 2. овог закона.
