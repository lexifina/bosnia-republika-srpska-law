# Члан 3.
У члану 15. у ст. 2. и 3. послије ријечи: "незапослена" ријечи: "шест мјесеци прије рођења дјетета" бришу се.
Послије става 3. додаје се нови став 4. који гласи:
"(4) Изузетно од става 2. право на матерински додатак може остварити мајка која има пребивалиште у Републици ако отац дјетета има пребивалиште у Републици најмање годину дана прије рођења дјетета".
