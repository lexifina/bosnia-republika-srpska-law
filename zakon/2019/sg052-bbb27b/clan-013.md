# Члан 13.
(1) Пореска управа Републике Српске електронским путем обавјештава Министарство о износу укупног подстицаја за привредни субјект по основу повећања плате радника.
(2) На основу обавјештења из става 1. овог члана, Министарство доноси рјешење за сваког појединачног привредног субјекта о одобравању подстицаја за повећање плате радника.
(3) Правоснажно рјешење из става 2. овог члана, Министарство уноси у Систем за управљање финансијским информацијама (СУФИ систем) ради плаћања.
