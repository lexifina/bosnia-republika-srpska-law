# Republika Srpska law in charts

Charts about the law of every country, from all of global-law: [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). This folder is for charts about Republika Srpska only.

**This is a placeholder.** No charts have been drawn from this repository yet.

When they are, this folder will hold one page of charts drawn only from this repository's data (its git history, its act folders and its tables in `data/` and `registry/data/`), in the same form as [serbia-law's](https://github.com/lexifina/serbia-law/tree/main/visualisations): a single HTML file with all its data inside, a still of every chart for this README, the data path, record count and limits under each chart, a table with every number, and the scripts that rebuild it (`src/`). The charts will be descriptive: they show what the sources record, not why.
